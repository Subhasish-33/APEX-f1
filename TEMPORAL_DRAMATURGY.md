# APEX-F1 Temporal Dramaturgy
# Phase 3.5 — Weekend Experience Orchestration

## 1. Live Experience Temporal Choreography
APEX-F1 abandons static "dashboards" for an emotionally rhythmic temporal interface. The UI breathes with the race state.

*   **The Grid Walk (Pre-Race)**: Expansive, atmospheric, photography-led. Layouts are magazine-like. Motion is slow, sweeping, and luxurious. 
*   **Lights Out (Lap 1)**: Chaotic, compressed, immediate. Photography vanishes. Data density spikes. The motion language shifts to harsh, instantaneous cuts. There are no smooth transitions during Lap 1.
*   **The Mid-Race Lull**: The UI exhales. Layouts widen. The storytelling engine shifts focus to strategic tire degradation graphs and predicted pit windows. Motion becomes a steady, metronomic tick.
*   **Safety Car / VSC**: The interface instantly cools down. Contrast drops. A dominant, rhythmic amber pulse takes over the background. Data polling visually slows to reflect the delta-time constraints. It is an emotional pause.
*   **The Final 5 Laps**: Claustrophobic compression. The interval between P1 and P2 consumes the viewport. Peripheral data (P15 vs P16) is aggressively dimmed or removed. Motion becomes violent and immediate.

## 2. Weekend Emotional States (Macro-Orchestration)
The entire platform behaves differently depending on the day of the week and championship context.

*   **Thursday (Media Day)**: Narrative-driven. Text-heavy. Driven by rumors, quotes, and legacy. The UI is bright, open, and exploratory.
*   **Friday (FP1 / FP2)**: Technical and investigative. The interface feels like an engineer's toolkit. Heavy on telemetry overlays, setup comparisons, and raw sector times.
*   **Saturday (Qualifying)**: The ultimate tension state. Everything is about the stopwatch. The UI strips away championship narratives and focuses entirely on instantaneous delta times.
*   **Sunday (Race Day)**: Grand, operatic, inevitable. The interface merges the narrative weight of Thursday with the ruthless precision of Saturday.

## 3. Motion Identity (State-Driven Physics)
Motion is no longer just "restrained"—it is ALIVE and context-aware.

*   **Qualifying Motion**: Hyper-responsive. Numbers tick with zero easing (`steps(1)`). Progress bars snap. It feels like a blade.
*   **Cooldown Lap Motion**: Easing curves become deeply elongated (`cubic-bezier(0.4, 0.0, 0.2, 1)`). The UI feels exhausted but triumphant. Elements fade in over 800ms instead of 200ms.
*   **Red Flag Motion**: Absolute stillness. All background scanning and telemetry ticking halts entirely. The silence is deafening.
*   **Rain / Chaos Motion**: Easing curves introduce slight, deliberate instability. Data blocks shuffle with minor delays, mimicking the unpredictability of the conditions.

## 4. The "Heartbeat" of APEX
The platform relies on a visual heartbeat. The base rhythm is set by the leader's lap time. When Verstappen sets a purple sector, the interface doesn't just change a hex code; the background gradient surges momentarily, perfectly synchronized with the telemetry packet arrival. This is instrument-grade temporal design.
